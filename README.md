# JennyLauncher — Custom Game Launcher & Store Browser  
A lightweight Windows launcher with a built‑in store browser, dark red UI, and a clean, focused layout designed for actually playing games — not managing bloat.

![Banner](https://via.placeholder.com/1200x260/1a0208/ff3040?text=JennyLauncher+by+foidstudios)

---

## 🚀 Overview
JennyLauncher is a custom Windows game launcher that combines:

- A **clean games library**
- A **built‑in WebView2 store browser**
- A **dark red gamer aesthetic**
- A **simple installer and portable build**
- A **custom window shape and animated boot screen**

It’s built for players who want a compact, fast, and visually distinct launcher without the clutter of mainstream platforms.

---

## 🎮 Features

### 🕹️ Game Library
- Auto‑detects popular games across all drives  
- Add custom games manually  
- Clean tile‑based layout  
- One‑click **PLAY** buttons  

### 🛒 Integrated Store Browser
- Powered by **WebView2**  
- Your store loads **inside** the launcher  
- No external browser windows  
- Popup override keeps all navigation internal  

### 🎨 Custom UI
- Dark red theme  
- Hex‑cut window shape  
- Matrix‑rain background animation  
- Smooth boot screen with animated title  

### ⚙️ Technical
- Built in C# (.NET)  
- WebView2 runtime support  
- Lightweight and fast  
- No telemetry, no tracking, no nonsense
